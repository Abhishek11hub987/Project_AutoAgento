# AutoAgento

AutoAgento is a virtual AI staffing agency disguised as a visual office platform. This is NOT a standard SaaS dashboard — it is a digital office where Indian businesses "hire" named, certified AI employees who occupy desks on a floor and deliver real business outcomes.

## Core Metaphor
- **Hire Employees, Don't Create Agents**: Every AI is a named avatar (Priya, Rahul, Anjali) with a job role, certification, and performance review.
- **Visual Office Floor**: Agents sit at desks with real-time status visible on the floor.
- **Outcome-Based**: A micro-business model where you only pay when an agent delivers a business outcome.

## Features
- **Native Indian Languages**: Hinglish, Hindi, Marathi, Tamil, Telugu support via Bhashini API.
- **Zero Cost MVP Stack**: Gemini API (Free Tier), React/Vite, FastAPI, SQLite.
- **Document Processing**: Automatic parsing of invoices and bank statements.
- **Human Escalation Network**: Built-in AI to Human handoff when thresholds are met.
